# Лабораторная работа №1

## Тема
Основы Python: переменные, списки, словари, множества, строки и циклы.

## Цель работы
Получить практические навыки работы с основными конструкциями языка Python:
переменными, списками, словарями, множествами, строками и циклами.

## Структура проекта

- `lab01/` — задания лабораторной работы;
- `main.py` — верхнеуровневый модуль проекта;
- `tests/` — автоматические тесты;
- `requirements.txt` — зависимости проекта;
- `README.md` — описание проекта.

## Запуск заданий
Для запуска отдельного задания используется команда:
python lab01/01_circle.py

## Запуск верхнеуровневого модуля
python main.py

## Запуск тестов
Для установки pytest:
pip install -r requirements.txt

## Для запуска тестов:
pytest -v
